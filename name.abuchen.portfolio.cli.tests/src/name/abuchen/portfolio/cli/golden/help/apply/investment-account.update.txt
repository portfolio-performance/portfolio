pp-cli apply operation investment-account.update: Updates an investment account by UUID. Only the fields present change; null or an empty string clears the note. A new reference cash account must already be in the file.

Input: one element of "operations" in the batch given with --input. Fields of the investment account; they match the investment-accounts output.
  operation (string, one of investment-account.update) Operation name.
  name (string, optional) Account name; never empty.
  referenceCashAccount (string, optional) UUID of the cash account that settles this account; it must already be in the file.
  note (string or null, optional) Note.
  retired (boolean, optional) Whether the investment account is retired.
  uuid (string) UUID of the investment account.

Failure codes (failures[].code of validation-failed):
  reference-not-found  No entity of the expected kind matches the reference.
  unknown-field  The object has no such field.
  required  A required field is missing or empty.
  invalid-type  A field has the wrong JSON type.
  duplicate-target  An earlier operation changes the entity.
